# 👋 Oi, eu sou o Lucas

**Construo software local e maneiras mais confiáveis de trabalhar com IA.**

Sou desenvolvedor autodidata do interior do Rio Grande do Sul. Também trabalho

### 🤖 IA além do uso de ferramentas

Uso Claude Code e Codex, mas também projeto o processo em que eles trabalham.
No [**AI Coop**](https://github.com/LucasCerattoRS/ai-coop), experimento um
protocolo para agentes colaborarem no mesmo repositório com tarefas explícitas,
worktrees isolados, handoffs verificáveis e revisão por commit exato. O objetivo
é reduzir perda de contexto e retrabalho, com decisões rastreáveis e controle
humano sobre a integração. É uma arquitetura em desenvolvimento, não uma
plataforma pronta.

Também estudo **IA no próprio dispositivo**: no
[**TranscritorNPU**](https://github.com/LucasCerattoRS/TranscritorNPU), uso
Whisper e OpenVINO para transcrever áudio e vídeo localmente com NPU, GPU ou CPU.
